This project is a front-end travel website developed as an assignment for the Human-Computer Interaction (HCI) course within the Computer Science program at Bina Nusantara University (BINUS). The website is designed with a strong focus on user interface (UI) and user experience (UX) principles to provide an intuitive platform for booking and exploring travel destinations.
